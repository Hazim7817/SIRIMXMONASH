# Drug-induced liver injury, NARROW definition (primary analysis).
#
# MedDRA preferred terms (PTs), British spelling, matched exactly in FAERS
# (case does not matter here; the script upper-cases them). Codes are
# MedDRA 29.1. All are hepatobiliary PTs that are 'narrow' in the SMQ
# 'Drug related hepatic disorders - severe events only' (20000007) or its
# cholestasis sibling, chosen to capture liver injury itself rather than
# lab abnormalities or other liver disease.
#
# Deliberately excluded:
#   - lab results: ALT/AST increased, Hepatic enzyme increased, Transaminases
#     increased, Liver function test abnormal, Blood bilirubin increased
#   - infections: Hepatitis A/B/C/E, Hepatitis B reactivation, Hepatitis viral
#   - chronic or other causes: Hepatic cirrhosis, Hepatic steatosis,
#     Ischaemic hepatitis, liver tumours
#
# PT lists change between MedDRA versions and the choice of terms changes
# the results. Compare with dili_extended.txt as a sensitivity analysis.
